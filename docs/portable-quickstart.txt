Deckstride — preview release

Windows: extract the ZIP and run deckstride.exe. Its icon is embedded.
Linux: extract the tarball and run ./deckstride. Optional menu/taskbar
integration: keep the extracted folder in a permanent location, then run
python3 install-linux-launcher.py. No root privileges are needed. Python is
only needed for this optional installer, never for running Deckstride.
To remove integration delete ~/.local/share/applications/deckstride.desktop
(or the corresponding file under your XDG_DATA_HOME).
Wayland shells use that desktop entry to resolve the application icon.

The executable includes the renderer, image codecs, fonts and window icon.
No runtime downloads or separately installed PDF renderer are required.
Linux uses the system desktop services and X11/Wayland libraries.
Run --licenses for bundled dependency notices. Open PDFs or picture folders
from Menu. Both Presenter and Slides windows start fullscreen.

Physical display, sleep prevention and clean-machine acceptance remain open.
This is a preview for testing, not a claim of production readiness.
