# PDF Presenter 0.1.17 preview

Portable PDF and image-folder presenter with fullscreen presenter/presentation
views, monitor routing/mirroring, notes, slide browser, themes and English/French.
Deck preparation reports progress, ETA and RAM use; prepared slides stay in memory.

This preview adds Linux/Windows application icons and release bundles. It includes
fixes for Windows file-dialog ownership/duplicate requests and output-host shutdown.
Windows embeds its Explorer/taskbar icon. Linux portable bundles include an optional
`python3 install-linux-launcher.py` for desktop menu and Wayland icon integration.
The executable runs without Python or a separately installed PDF renderer.

Use the Windows portable ZIP or Linux portable tarball, extract and run the binary.
Raw binaries and cargo-binstall archives are also provided. Verify SHA256SUMS.

Physical multi-monitor behavior, sleep prevention, clean-machine compatibility,
and sustained performance still require user acceptance. Windows binaries are
unsigned. macOS binaries are not part of this preview.
