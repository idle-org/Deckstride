# Deckstride 0.1.78 preview

This preview focuses on Windows presentation responsiveness and desktop integration:

- **Faster audience overlays.** Each audience window keeps one bounded base
  framebuffer and reuses it for pointer and annotation updates. Moving the pointer
  no longer rescales and rasterizes the full slide every time. Slide, zoom, color,
  DPI, blanking and resize changes invalidate the cache; recovery controls bypass
  it. The additional cache is capped at 64 MiB per audience window.
- **Cleaner Windows startup.** The release executable uses the Windows GUI subsystem,
  so opening it does not create a terminal window. Audience windows are created
  without activation and the presenter explicitly requests focus when first shown.
- **PDF file icon and association.** Use **Menu → Preferences → Windows integration
  → Choose as PDF app…**. Deckstride registers its executable, open command and
  embedded icon for the current user, refreshes Explorer and opens Default Apps.
  Windows requires you to confirm the default PDF application there. Keep the
  portable folder in a permanent location and repeat this action after moving it.

## Windows testing

Extract the Windows x86_64 portable ZIP and run **deckstride.exe**. Confirm that
no terminal appears and that the presenter accepts keyboard input immediately while
the audience window remains on the selected output. On a high-resolution audience
display, compare pointer, arrow and highlighter tracking with 0.1.77, including zoom
and mirrored audience outputs.

Register Deckstride in Preferences, select it for `.pdf` in Default Apps, then
check that Explorer shows the Deckstride icon and double-clicking a PDF opens it.
The executable is unsigned, and the association is per user without administrator
rights.

## Validation and packages

Linux all-feature tests, 13 Python helper tests, formatting, warnings-denied
Clippy/rustdoc and the optimized build pass. Headless whole-application line
coverage is **68.39%**, exceeding its 60% CI floor. Full GUI coverage could not run
locally because Xvfb is unavailable.

Linux x86_64 and Windows x86_64 standalone executables, portable bundles, Cargo
binstall archives and SHA-256 checksums are provided. macOS is not packaged.
Windows runtime, physical multiscreen, initial-focus, association, clean-machine,
sleep and performance acceptance remain open; this is a preview for testing.
