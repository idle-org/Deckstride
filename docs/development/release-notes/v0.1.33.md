# Deckstride 0.1.33 preview

Portable PDF and image-folder presenter for Linux and Windows x86_64. This preview
includes the changes since 0.1.24:

- Transparent PDF areas display on white by default. Appearance offers separate
  Page background and Fit padding color controls. Correct PDF alpha conversion
  prevents dark translucent edges; older PDF caches are regenerated automatically.
- Shift+Space moves back; Space advances. The last slide shows an End of slides
  placeholder in the presenter's Next preview only, never on audience output.
- Display rectangles reflect monitor aspect ratios. Apply changes retains the
  15-second Keep/Revert trial. Windowed mode warns about positioning issues,
  especially on Linux, and recommends fullscreen if affected.
- All slides supplies Linux Wayland parent and X11 transient/dialog hints so
  tiling desktops can float it, while keeping it resizable and non-modal.
- Jenkins runs without Xvfb with a temporary 60% headless coverage floor. The local
  full-GUI floor remains 75%; all production code stays included.

Download and extract the Windows portable ZIP or Linux portable tarball, then run
its executable. Raw binaries and cargo-binstall archives are also provided; verify
SHA256SUMS. The Linux bundle includes an optional desktop-launcher installer.
Existing version-1 settings remain compatible; source documents are unchanged.

Linux validation includes workspace and native X11 tests, formatting, warnings-denied
Clippy/rustdoc, Python checks and 86.38% whole-application coverage. A Wayland protocol
regression verifies the browser's parent hint before its first buffer; actual X11
window properties were also inspected. Niri-specific placement, physical multiscreen,
sleep, performance and clean-machine acceptance remain open. Windows runtime testing
of these changes is pending; binaries are unsigned. No macOS binary is included.
