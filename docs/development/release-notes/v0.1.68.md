# PDF Presenter 0.1.68 preview

This preview adds live presentation tools while preserving the buffered rendering
path. Open **Tools** in the presenter header for a low-latency pointer, straight
arrows and translucent highlighting. Tool updates use bounded vector state over the
existing slide texture; they do not rerender the PDF or read slide files. Large arrows
now keep a clean, proportional filled head at every configured size.

## Highlights since 0.1.33

- Edit notes per slide in an asynchronous sidecar editor. Import TXT notes separated
  by dashed lines or Markdown notes split at headings, with review before saving.
- Enable shared presenter/output page zoom when needed. Scroll to zoom, drag to pan,
  or double-click to fit the page width near the clicked position. Zoom reuses the
  buffered slide image.
- Configure elapsed/countdown timing, start/pause/reset behavior, large timer text,
  six side positions and an optional sized slide-progress bar.
- Use the redesigned resizable Layout and All slides windows. Browser thumbnails fit
  the available width, double-click opens a safe preview, and loading labels now
  distinguish RAM, disk cache, queued and active work.
- Size the default decoded-slide buffer from available RAM. Rolling-buffer status and
  preparation feedback remain explicit without covering a hidden footer.
- Keep display, layout, fullscreen and timer controls directly available in the
  presenter header. Presentation visibility survives fullscreen, routing and host
  recovery unless the operator explicitly blanks it.

## Packages

The release provides portable Linux x86_64 and Windows x86_64 bundles, standalone
binaries, Cargo binstall archives and SHA-256 checksums. No Rust or PDF renderer is
required at runtime. The Windows build is unsigned. macOS is not packaged in this
preview.

Physical multi-monitor routing, sleep inhibition, pointer latency and appearance
should still be rehearsed on the exact machines and displays used for a live event.
