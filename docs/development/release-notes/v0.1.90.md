# PDF Presenter 0.1.90 preview

This preview adds display controls and an optional single-screen presentation view.

- **Single-screen view.** Select Single screen in Displays for full-window slides
  with controls revealed at the top and bottom edges. The app offers this mode
  only when it starts with exactly one screen, explaining that PDF Presenter is
  intended for separate Presenter and Slides screens. Later disconnects never
  trigger the offer. Saved Presenter layouts and the independent audience host
  remain separate; controls overlay the slide without resizing it.
- **Per-screen window modes.** Choose Follow global, Always fullscreen or Always
  windowed. Overrides ignore global fullscreen commands, follow the monitor, and
  use the existing Apply / Keep / Revert confirmation.
- **Hold S to swap.** Hold S for one second in Presenter or All slides to swap
  Presenter and Slides groups with a timed confirmation. Single screen assignments
  remain in place. Short taps and keyboard repeats do not repeatedly swap screens.
- **Confirmed quitting.** Escape and Ctrl+Q request a Quit presentation dialog;
  Cancel or Escape continues the show. Unsaved notes remain protected. Escape
  still reverts an active display trial first. Audience shortcuts request the
  confirmation on Presenter without showing operator dialogs or blanking Slides.
- **Installation documentation.** The README includes application screenshots and
  a repository-based cargo-binstall command for published releases.

## Validation and packages

Linux formatting, warnings-denied Clippy/rustdoc, workspace tests, build and 13
Python helper tests pass for the implementation. Regression coverage includes
startup-only eligibility, disconnect sequences, settings round trips, display
trials, quit confirmation, edge controls, fixed slide geometry and texture reuse.
Full GUI coverage also passes outside the restricted sandbox: **84.83%** against
the 75% floor, including native-window tests. These checks do not establish physical
multiscreen, clean-machine or measured presentation-latency acceptance.

Linux x86_64 and Windows x86_64 standalone binaries, cargo-binstall archives,
portable bundles and SHA-256 checksums are provided. Windows is unsigned. This
release does not include a new macOS build; v0.1.83 retains its one-off Apple
Silicon preview. Native Windows runtime, clean-machine, physical multiscreen,
sleep and measured latency acceptance remain open. Test the actual presentation
computer and display arrangement before a live event.
