# Deckstride 0.1.96

This is the first release under the **Deckstride** name. The application, executable,
portable archives, desktop integration and repository now use the new identity. The
established application icon remains unchanged.

## What changed since 0.1.91

- Add automatic playback with a configurable slide interval and optional looping.
  Playback waits until the requested slide is visible and pauses for dialogs and
  safety states.
- Add built-in Spanish, Japanese, Simplified Chinese, German and Brazilian Portuguese
  alongside English and French, with offline system-language detection.
- Show the open PDF or picture-folder path in the Presenter footer and show the
  running portable executable path in Preferences.
- Preserve existing user settings during the Deckstride rename and continue using
  an existing warm rendered-slide cache instead of forcing every presentation to
  render again.

The existing multiscreen routing, mirrored Presenter or Slides outputs, per-screen
layouts, buffered rendering, notes, zoom, pointer tools and display recovery remain
the core of the release.

## Downloads

Portable packages and cargo-binstall archives are provided for:

- Linux x86_64 GNU
- Linux ARM64 musl
- Windows x86_64 GNU
- Apple Silicon macOS 13+
- Intel macOS 13+

Windows and macOS packages are unsigned. The macOS packages are cross-built on Linux
and include the release-page command for opening an unsigned application. Rehearse on
the actual presentation computer, adapters and display arrangement before a live
event.

## Validation

Linux formatting, warnings-denied Clippy and rustdoc, the complete Rust workspace
test suite, and all 13 Python CI/launcher tests pass. Windows multi-screen behavior
has been extensively tested in earlier releases; native runtime testing of these new
archives remains appropriate before use in a live show.
