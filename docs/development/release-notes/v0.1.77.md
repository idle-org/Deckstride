# Deckstride 0.1.77 preview

This preview adds two features since 0.1.75:

- **Independent presenter layouts per display.** Customize each presenter's widgets,
  sizes, positions, bars and presets, with saved defaults and project overrides
  tied to its monitor. Timer behavior and start/pause/reset remain shared; each
  presenter chooses its own timer appearance.
- **Custom blank picture.** Use **Preferences → Blank presentation → Choose
  picture…** to select the picture shown by the existing blank button/B shortcut.
  A bounded copy is saved across restarts and fitted on all audience outputs
  against black. **Use solid black** restores the default. Slide zoom and
  annotations do not affect the picture.

The monitor synchronization/reconnection, shared display confirmation and held
navigation fixes from 0.1.75 remain included.

## Windows testing

Download the Windows x86_64 standalone executable, or extract the portable ZIP
and run **deckstride.exe**. No Rust toolchain or separately installed PDF
backend is required. The executable is unsigned.

With two presenters and an audience display, customize the presenters differently,
save their layouts and restart/reconnect the monitors. Verify that the layouts
follow their displays while timer controls remain shared. Choose a blank picture,
blank/unblank, restart, and switch back to solid black. Also check the previous
three-monitor synchronization, one-click confirmation and hotplug fixes.

## Validation and packages

Linux workspace/native tests, 13 Python helper tests, formatting, warnings-denied
Clippy/rustdoc and the optimized build pass. Whole-application line coverage is
**84.56%**, exceeding the 75% floor.

Linux x86_64 and Windows x86_64 standalone executables, portable bundles, Cargo
binstall archives and SHA-256 checksums are provided. macOS is not packaged.
Windows runtime, physical multiscreen, clean-machine, sleep and performance
acceptance remain open; this is a preview for testing.
