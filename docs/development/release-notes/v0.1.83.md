# PDF Presenter 0.1.83 preview

This preview improves settings organization and makes presentation tools easier to
judge across Presenter previews and high-resolution Slides screens.

- **A clearer Preferences window.** Advanced settings now live in a resizable,
  scrollable window. Blank-output artwork, Windows PDF integration, RAM and disk
  cache controls, cleanup, preparation status and storage paths no longer crowd the
  Menu dropdown. Zoom, fitted-area behavior and automatic Slides output remain in
  Menu for quick access.
- **Consistent tool sizing.** Pointer, highlighter and arrow dimensions scale with
  the visible slide height. Their relative size now stays comparable in the smaller
  Presenter preview, on 1080p output, on 4K output and across OS display scaling.
  The maximum selectable size increases from 32 to 48; on a 4K Slides screen it is
  rendered at roughly twice the physical width used on 1080p.
- **Transparent project information.** The README states the MIT license and notes
  that development uses LLM-generated or LLM-assisted code with human review.

## Validation and packages

Formatting, warnings-denied Clippy and rustdoc, 129 automated Rust tests and 13
Python build-helper tests pass on Linux. The tool-size path remains a lightweight
vector overlay and does not rerender slide images. Windows-target validation on the
release builder includes the embedded application icon; local cross-Clippy could not
pass that resource step because MinGW `windres` is unavailable on the host.
The memory-budget probe is pinned to a Rust 1.93-compatible dependency for the
pinned Apple cross-build toolchain.

Linux x86_64, Windows x86_64 and, for this release, Apple Silicon macOS 13+
standalone executables, Cargo binstall archives and SHA-256 checksums are provided.
Linux and Windows also receive portable bundles. The macOS executable is unsigned
and cross-built from Linux; native Mac startup and multiscreen behavior have not
been tested. Windows runtime, physical multiscreen, clean-machine, sleep and
performance acceptance remain open; this is a preview for testing.
