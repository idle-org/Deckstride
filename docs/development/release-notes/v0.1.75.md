# PDF Presenter 0.1.75 preview

This preview includes the monitor and navigation fixes since 0.1.71:

- Remove an idle repaint loop that could delay other selected monitors until their
  windows were clicked. Each window now follows its own bounded repaint deadlines.
- Reapply window placement after unplug/replug and monitor-layout changes, even
  when the selected monitor IDs and fullscreen flags remain unchanged.
- Refresh all presenters when a display trial changes. One **Keep changes** click
  on either presenter confirms the entire setup and dismisses both dialogs.
- Closing **All slides** with Escape preserves the live show, including when focus
  moves to an audience window. **B** remains the explicit blank shortcut.
- Hold Next/Previous or navigation keys to accelerate from individual slides to
  bounded batches. Rendering coalesces destinations and stops on release/focus loss.

The disk-cache size/lifetime controls and once-per-startup cleanup from 0.1.71
remain included.

## Windows testing

Use the Windows x86_64 standalone executable or extract the portable ZIP and run
**pdf-presenter.exe**. No Rust toolchain or separately installed PDF backend is
required. The executable is unsigned.

Please exercise three displays with two presenters and one audience output:
confirm a display change once from either presenter; verify every selected presenter
appears without clicking its window; unplug/replug the third and middle displays;
and check that the live slide and blank state survive. Also test Escape in All
slides and held navigation in both directions. These physical Windows behaviors
remain acceptance checks, not claims established by the Linux tests.

## Validation and packages

Linux formatting, warnings-denied Clippy/rustdoc, workspace/native tests, and 13
Python helper tests pass. Whole-application coverage is **84.56%** (75% floor).
Regression tests cover three native windows without clicks, topology invalidation,
repeated simulated third/middle-monitor reconnects, and one-click confirmation
across two independent presenter contexts.

Linux x86_64 and Windows x86_64 standalone binaries, portable bundles, Cargo
binstall archives and SHA-256 checksums are provided. macOS is not packaged.
Windows runtime, physical multiscreen, clean-machine, sleep and performance
acceptance remain open; this is a preview for testing.
