# Deckstride 0.1.24 preview

Portable PDF and image-folder presenter for Linux and Windows x86_64, with separate
fullscreen presenter/presentation views, monitor routing/mirroring, notes, slide
browser, themes and English/French controls. No separate PDF renderer is required.

- Confirm display changes with a 15-second Keep/Revert trial and automatic rollback.
  Startup right-click swap helps recover initially reversed screens.
- Keep nested settings menus open while choosing themes/languages or adjusting options.
- Compact hide/pin icons at the far left of both presenter bars.
- Separate elapsed-time and clock boxes, independently placed in the header, above
  slides or below notes. Optional slide/total progress bar; save per project or globally.
- Rolling RAM buffers evict distant slides and prepare the rest of large decks;
  processed frames are reused from disk when they no longer fit in memory.
- Embedded Linux/Windows icons, owned Windows file dialogs with duplicate-request
  protection, and bounded output-host shutdown.

Download the Windows portable ZIP or Linux portable tarball, extract and run.
Raw executables and cargo-binstall archives are also available. Verify SHA256SUMS.
Linux bundles include an optional Python desktop-launcher installer; the application
itself does not need Python. Existing version-1 settings remain compatible.

Linux validation includes formatting, warnings-denied Clippy/rustdoc, workspace
and native GUI tests, Python helper tests and 86.42% whole-application line coverage.
Physical multiscreen, sleep prevention and clean-machine acceptance remain open.
Windows binaries are unsigned; native Windows validation of these latest changes
is pending. macOS binaries are not included in this preview.
