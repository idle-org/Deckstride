# PDF Presenter 0.1.91

PDF Presenter releases are now regular releases rather than previews. The version
remains below 1.0 while the project continues to refine platform integration and
physical-display acceptance.

## Expanded platform packages

This release provides standalone binaries, cargo-binstall archives, portable
bundles and SHA-256 checksums for:

- Linux x86_64 GNU
- Linux ARM64 musl
- Windows x86_64 GNU
- Apple Silicon macOS 13+
- Intel macOS 13+

The Linux ARM64 build uses musl for a portable executable. Both macOS builds use a
pinned cross-build image and macOS 13 deployment target. Windows and macOS builds
are unsigned. The release page includes the commands needed to run the unsigned
macOS archives.

## Validation

Linux formatting, warnings-denied Clippy/rustdoc, workspace tests, build and 13
Python helper tests pass. Full GUI coverage is **84.79%** against the 75% floor.
The release pipeline also verifies target architecture, archive layout, checksums,
system-library dependencies and isolated cargo-binstall extraction for every
target. Linux x86_64 receives the native-window smoke test. macOS artifacts cannot
be executed on the Linux release host, and native Windows/macOS runtime,
clean-machine and physical multiscreen acceptance remain open. Rehearse on the
actual presentation computer and display arrangement before a live event.
